## 3. Тест-кейсы

### TC-001: Получение ключей из Боевого пропуска

| Поле | Значение |
|------|----------|
| **ID** | TC-001 |
| **Название** | Выдача ключей за уровень БП |
| **Предусловие** | Игрок участвует в ивенте, БП активен |
| **Шаги** | 1. Достичь уровня БП, где положены ключи<br>2. Забрать награду |
| **Ожидаемый результат** | Ключи зачислены, счётчик обновился |
| **Постусловие** | Ключи отображаются в инвентаре |

### TC-002: Покупка ключей в магазине

| Поле | Значение |
|------|----------|
| **ID** | TC-002 |
| **Название** | Успешная покупка лота с ключами |
| **Предусловие** | Игрок авторизован, есть средства |
| **Шаги** | 1. Открыть магазин ключей<br>2. Выбрать лот<br>3. Подтвердить покупку |
| **Ожидаемый результат** | Ключи зачислены, баланс обновлён, чек получен |
| **Постусловие** | Покупка в истории |

### TC-003: Открытие одного чемодана

| Поле | Значение |
|------|----------|
| **ID** | TC-003 |
| **Название** | Открытие чемодана за 1 ключ |
| **Предусловие** | На поле есть чемодан, у игрока ≥1 ключ |
| **Шаги** | 1. Нажать на чемодан<br>2. Подтвердить открытие |
| **Ожидаемый результат** | Ключ списан, чемодан открыт, награда получена |
| **Постусловие** | Чемодан исчез с поля |

### TC-004: Открытие чемодана без ключей
